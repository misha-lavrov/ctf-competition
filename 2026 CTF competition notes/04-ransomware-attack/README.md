# 4. Ransomware Attack (Memory Forensics)

Аналіз дампу памʼяті після атаки ransomware, реверс алгоритму шифрування,
розшифровка файлу-заручника.

**Тип:** Memory Forensics + Reverse Engineering
**Інструменти:** Volatility 3, radare2, aeskeyfind, strings, pycryptodome
**Статус:** ⚠️ 10 з 11 підзадач вирішені й підтверджені платформою (100 балів
кожна). Підзадача 11 (фінальний прапор) не завершена — див. розділ "Що доробити"
у файлі з розвʼязанням.

## Файли
- [`01-task.md`](01-task.md) — умова задачі, всі 11 підзадач, пояснення типу, статуси
- [`02-solution.md`](02-solution.md) — покрокове розвʼязання з поясненням кожної команди
- [`../files/04-ransomware-attack/`](../files/04-ransomware-attack/) — оригінальні файли задачі (локально, не в git — див. `../README.md`)

## Ключові навички
- Читання дампу памʼяті (процеси, DLL, мережа) через Volatility
- Витягування файлу вірусу з памʼяті
- Пошук захованих рядків і hex-декодування
- Пошук AES-ключа в памʼяті (aeskeyfind)
- Розшифровка AES-CBC
