# 6. Flag Eater

Reverse engineering ELF-бінарника (Linux, stripped) з вкладеним dropper'ом і
XOR-шифром на основі `time()`-seed для `rand()`.

**Категорія:** Reverse Engineering · **Бали:** 600 · **Спроб:** 5
**Статус:** ✅ прапор підтверджено (через Discord команди, повний brute-force
не був доведений до кінця в цьому чаті)
**Інструменти:** file, strings, objdump, ldd, radare2, LD_PRELOAD-хук, brute-force (C)

## Файли
- [`01-task.md`](01-task.md) — умова задачі, надані файли, фінальний прапор
- [`02-solution.md`](02-solution.md) — покрокове розвʼязання з поясненням кожного інструмента
- [`../files/06-flag-eater/FlagEater.zip`](../files/06-flag-eater/) — оригінальні файли задачі (локально, не в git)

## Ключові навички
- `file` / `strings` — перший огляд невідомого бінарника
- `objdump -T` / `ldd` — імпортовані функції навіть у stripped-файлі
- Диференціальний аналіз (відомий вхід → порівняння виходу)
- radare2: `afl`, `pdf @ main`, `wtf` — витяг вбудованого бінарника (dropper)
- `LD_PRELOAD`-хук — перевірка гіпотези про `time`/`srand`/`rand` наживо
- Brute-force вузького вікна `time()`-seed за приблизною датою файлу
