# Інструменти: що ставити заздалегідь наступного разу

Організатори офіційно вимагали встановити наперед лише **OpenVPN-клієнт** (для
підключення до інфраструктури) і **Discord** (для комунікації) — див.
[`event-info.md`](event-info.md). На практиці майже кожна задача одразу
впиралась у те, що на ноутбуці більше **нічого не було** — а це Windows-ноути,
з якими студенти звикли працювати, тож насамперед бракувало Linux-оточення.
Через це чимало часу під час змагання пішло на встановлення WSL і пакетів
"по ходу", замість вирішення задач. Цей файл — список того, що варто поставити
**до** наступного туру.

## 0. Головне: WSL

Майже кожна задача (1, 3, 4, 5, 6, 7) вирішувалась через **WSL** (Windows
Subsystem for Linux) — Linux-оточення всередині Windows, бо переважна
більшість CTF/forensics/RE-інструментів існує тільки під Linux.

```powershell
wsl --install
```

- Потребує перезавантаження й створення користувача Ubuntu після встановлення.
- Потребує **прав адміністратора** на ноутбуці (офіційно було дозволено, але
  перевір заздалегідь, що вони реально є).
- Диски Windows доступні з WSL під `/mnt/c/`, `/mnt/d/` тощо — для важких файлів
  (дампи пам'яті, великі архіви) швидше спочатку скопіювати їх у "рідну"
  файлову систему WSL (`~/ctf/...`), а не працювати напряму через `/mnt/...`.

Детальніше: https://learn.microsoft.com/en-us/windows/wsl/install

## 1. Один рядок для всього apt-набору

Все, що знадобилось хоч у одній задачі, одним рядком (виконати в WSL/Ubuntu
після встановлення):

```bash
sudo apt update && sudo apt install -y \
  nmap hydra wget curl \
  tshark wireshark tcpdump ngrep \
  binwalk foremost \
  radare2 \
  python3-pip python3-venv \
  build-essential gcc \
  unzip \
  aeskeyfind
```

> Під час встановлення `wireshark`/`tshark` дебіанівський інсталятор може
> запитати "дозволити непривілейованим користувачам захоплювати пакети" —
> для CTF (аналіз готових `.pcap`, а не live capture) відповідь не критична,
> можна погодитись.

## 2. Python-пакети (pip)

```bash
pip3 install volatility3 oletools pycryptodome --break-system-packages
```

| Пакет | Для чого | Використано в |
|---|---|---|
| `volatility3` (команда `vol`) | Аналіз дампів оперативної пам'яті | Задачі 4, 5 |
| `oletools` (команда `olevba`) | Пошук VBA-макросів у Office-файлах | Задача 5 |
| `pycryptodome` | AES/шифрування в Python-скриптах | Задача 4 |

## 3. Словники паролів

```bash
mkdir -p ~/wordlists && cd ~/wordlists
wget https://github.com/praetorian-inc/Hob0Rules/raw/master/wordlists/rockyou.txt.gz
gunzip rockyou.txt.gz
```

`rockyou.txt` знадобився для `hydra` (brute-force паролів по SSH) у задачі 3.
Краще мати його завантаженим заздалегідь — 14+ млн рядків, і на змаганні може
не бути гарного інтернету для швидкого завантаження.

## 5. Що НЕ треба ставити окремо

- **Google Dorks / OSINT** (задача 1) — просто браузер, нічого встановлювати не треба.
- **RDP (mstsc)** і **PowerShell** — вже вбудовані у Windows.
- **Windows Security / Defender GUI** — перевірка карантину, теж вбудована.

## 6. Практична порада на майбутнє

Встанови все з пунктів 0–3 **за день-два до змагання**, поки є нормальний
інтернет і час розібратись з можливими помилками встановлення — а не в перші
15–30 хвилин туру, коли кожна хвилина вже йде в залік. Якщо права
адміністратора на видані ноутбуки видають лише в день змагання — постав
WSL і весь список одразу після отримання прав, ще до організаційного
брифінгу.
