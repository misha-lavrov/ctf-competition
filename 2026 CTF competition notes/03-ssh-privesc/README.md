# 3. SSH / Linux Privilege Escalation

Проникнення на сервер по SSH і підвищення привілеїв до root через ланцюжок
недбалостей адміністратора.

**Тип:** Мережеве проникнення + Privilege Escalation
**Статус:** ✅ всі 3 підзадачі вирішено й підтверджено
**Інструменти:** nmap, hydra, ssh, scp, cron
**Ланцюжок:** veronica → michael → steve → root
