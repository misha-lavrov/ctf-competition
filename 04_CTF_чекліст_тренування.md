# CTF — чекліст тренування задач

> Версія: 1.0  
> Оновлено: 6 вересня 2026  
> Ціль: пройти короткий, різноплановий маршрут до Чемпіонату Вінницької області з CTF

## Як користуватися

1. Обери **один** основний маршрут: picoCTF або CTFlearn. Не треба проходити обидва.
2. На одну задачу дай собі 10–15 хвилин чесної спроби; лише потім бери hint або став точне запитання.
3. Після кожної задачі заповни короткий коментар. Важливо не просто здати flag, а зрозуміти патерн.
4. Якщо назву picoCTF-задачі не знаходить пошук — пропусти її та бери наступну того самого напряму.

Позначки: `[ ]` — не почато, `[x]` — пройдено.  
Статус у коментарі: `сам`, `з hint`, `із розбором`, `відкладено`.

## Маршрут A — picoCTF / CyLab Security Academy

Платформа: [picoCTF Practice](https://play.picoctf.org/practice).  
Це рекомендований маршрут для мене як тренера: він охоплює Git, кодування, Forensics і Web та займає орієнтовно 2–3 години разом із нотатками.

### [ ] 1. First Find

- Напрям: General Skills / Linux
- Орієнтир: навігація файлами, `find`, `cat`
- Час: 5–10 хв
- Мета: знайти файл не вручну, а командою.

**Коментар після задачі**

```text
Статус:
Час:
Що дали:
Що перевірив:
Ключова команда / ідея:
Що запам'ятав:
Питання або коментар:
```

### [ ] 2. MY GIT

- Напрям: General Skills / Git
- Орієнтир: README, локальні `git config user.name` і `user.email`, commit metadata
- Час: 10–20 хв
- Мета: зрозуміти, чому ім'я та email автора коміту — не доказ особи.

**Коментар після задачі**

```text
Статус:
Час:
Яку вимогу знайшов у README:
Які Git-команди використав:
Security-висновок:
Питання або коментар:
```

### [ ] 3. The Numbers

- Напрям: Crypto / Encoding
- Орієнтир: перетворення чисел на символи
- Час: 10–15 хв
- Мета: навчитися спершу визначати представлення даних, а не «ламати шифр» навмання.

**Коментар після задачі**

```text
Статус:
Час:
На що були схожі дані:
Як перевірив гіпотезу:
Ключова ідея:
Питання або коментар:
```

### [ ] 4. information

- Напрям: Forensics
- Орієнтир: metadata, `exiftool`
- Час: 10–15 хв
- Мета: відпрацювати обов'язкову перевірку metadata у файлах.

**Коментар після задачі**

```text
Статус:
Час:
Тип файла:
Що показав exiftool:
Ключова знахідка:
Питання або коментар:
```

### [ ] 5. Glory of the Garden

- Напрям: Forensics
- Орієнтир: `strings`, пошук читабельних даних у файлі
- Час: 10–20 хв
- Мета: запам'ятати, що файл-картинка може містити корисний текст або приєднані дані.

**Коментар після задачі**

```text
Статус:
Час:
Які перші перевірки зробив:
Яка команда дала зачіпку:
Де саме були дані:
Питання або коментар:
```

### [ ] 6. GET aHEAD

- Напрям: Web / HTTP
- Орієнтир: HTTP-методи, `curl -I`, response headers
- Час: 10–20 хв
- Мета: побачити, що різні HTTP-методи можуть давати різну поведінку сервера.

**Коментар після задачі**

```text
Статус:
Час:
Які HTTP-методи перевірив:
Що змінилося у відповіді сервера:
Ключова ідея:
Питання або коментар:
```

### [ ] 7. Cookies

- Напрям: Web
- Орієнтир: browser cookies, DevTools → Application/Storage
- Час: 10–20 хв
- Мета: зрозуміти, які дані клієнт може змінювати і чому сервер має їх перевіряти.

**Коментар після задачі**

```text
Статус:
Час:
Який cookie / параметр був важливий:
Де його переглянув або змінив:
Чому така перевірка небезпечна для реального сервісу:
Питання або коментар:
```
