# CTF 2026 — підготовка та підсумки

Матеріали команди студентів для Чемпіонату Вінницької області з CTF
(кібербезпека, формат Jeopardy, 18.09.2026): як готувались до змагання і що
реально було на змаганні.

## Структура

| Папка | Що всередині |
|---|---|
| [`CTF overview and training plan/`](CTF%20overview%20and%20training%20plan/) | Матеріали **до** змагання: загальний план підготовки, плани тренера й студентів, конспект, чекліст тренувань, командна робота |
| [`2026 CTF competition notes/`](2026%20CTF%20competition%20notes/) | Підсумки **після** змагання: умови й розбори 7 задач, правила та FAQ організаторів, чекліст інструментів, тренувальні задачі для наступних турів |

Початок роботи з нотатками змагання — у
[`2026 CTF competition notes/README.md`](2026%20CTF%20competition%20notes/README.md):
там таблиця всіх задач зі статусами та список того, чого ще бракує.

## Примітка про git

Оригінальні файли задач (архіви, дампи пам'яті, pcap) можуть важити
гігабайти, тому `2026 CTF competition notes/files/` додана в `.gitignore` і в
репозиторій не потрапляє.
